== Couchbase Operational Cluster Feature Compatibility

// tag::feature-compat[]
All of the SDKs have API compatibility with most of the features in Couchbase Operational Clusters --
whether self-managed, or Capella.
The following table covers possible exceptions, and gives the version of the {name-sdk} and Couchbase Server with which some features were introduced.


.Couchbase Server and SDK Supported Version Matrix
[.table-merge-cells]
[cols="8,5,5,5"]
|===
| | Server 7.2 | Server 7.6.x  | Server 8.0

| KV Range Scan
| N/A
2+| From 3.4.1

| Zone aware replica reads
| N/A
2+| From 3.6.0

| Vector Search with Search Vector Index
| N/A
2+| From 3.6.0

| Vector Query using Hyperscale Vector Index
2+| N/A
| From SDK 3.9.0 ①

| Vector Query using Composite (GSI & vector) index
2+| N/A
| From SDK 3.9.0 ①

| Distributed ACID Transactions  
3+| From 3.0.0

| DNS SRV refresh for serverless environments (AWS Lambda, Azure Functions, and GCP Functions)
3+| From 3.4.0

| Circuit Breakers
3+| From 3.0.0

| Response Time Observability with OTel 
3+| From 3.0.7

| Field Level Encryption 
3+| From 2.6.0

| Cloud Native Gateway  
3+| From 3.5.0
|===

<1> As part of the standard SDK {sqlpp} API, it should be compatible with all earlier versions of the SDK -- but it has not been tested.
